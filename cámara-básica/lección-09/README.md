# Lección 09: El Nivel del Ser

- ¿Qué es el SER?. Es nuestro principio Divino.
- La escalera maravillosa. La Cruz Horizontal y Vertical.
- El reflejo de lo que  interiormente llevamos.
  
## Ítems
1. Que el que anhele un cambio radical debe comprender en qué Nivel del SER está.
2. Que el Nivel del SER que tenemos en este momento es la base para adquirir niveles superiores.
3. Que así como es posible superarnos materialmente, también lo podemos hacer en nuestro mundo espiritual.

## Práctica
- La Concentración
